# Urvi Tours & Travells

live demo:
https://urvi-tours-and-travells.vercel.app/

Features:
- AC and Non-AC car pricing
- Separate rate per km for AC and Non-AC vehicles
- Driver allowance per day configuration
- Multiple photos per car
- Booking inquiry flow and admin management

This project uses a React frontend and a Node/Express backend with MySQL-compatible database support.
